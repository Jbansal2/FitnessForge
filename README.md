# FitnessForge - Gym Website 🏋️‍♂️

[![FitnessForge Project](https://res.cloudinary.com/dezt3uhp4/image/upload/v1734976214/Screenshot_2024-12-23_230421_busaaw.png)](https://fitnessforge.netlify.app)


**FitnessForge** is a sleek and responsive gym website designed to inspire fitness enthusiasts and promote health and wellness. Built using modern web technologies, it showcases essential features for gym members and visitors, such as class schedules, membership plans, testimonials, and more.

## 🚀 Live Demo  
Check out the live version here: [FitnessForge](https://fitnessforge.netlify.app)

---

## 🌟 Features  
- **Responsive Design**: Optimized for all devices – desktop, tablet, and mobile.  
- **Membership Plans**: Explore various membership tiers to suit diverse fitness needs.  
- **Protein Shop**: Easy-to-buy protein and supplements directly from the website.  
- **User Login**: Secure login functionality for members. 

---

## 🔧 Technologies Used  
- **HTML5**: Semantic structure and accessibility.  
- **CSS3**: Modern styling techniques, including animations and transitions.  
- **JavaScript**: Interactivity and dynamic elements.  
- **Netlify**: Hosting and deployment.
